# Jennifer Pearl 2028 Gateway — Quality Upgrade Overlay

This ZIP is a non-destructive upgrade package for:

https://github.com/vervenveda/JenniferPearl2028.github.io

It adds a baseline audit, installation guide, upgrade roadmap, a Python standard-library HTML checker, and a GitHub Actions workflow.

**It does not replace or modify `index.html`.** Upload the contents of this folder into the repository root, preserving folder structure.

Start with:
- `BASELINE-AUDIT.md`
- `docs/INSTALL-UPGRADE.md`
- `docs/UPGRADE-ROADMAP.md`

The checker is intentionally structural and offline. It does not claim to verify external links, browser rendering, accessibility conformance, or live deployment.
